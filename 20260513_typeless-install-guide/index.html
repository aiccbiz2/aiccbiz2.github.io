Typeless 설치 가이드

Typeless는 음성을 깔끔한 텍스트로 바꿔주는 AI 받아쓰기 도구입니다. 어떤 앱이든 커서가 놓인 자리에 바로 입력되며, 한국어와 영어를 자동으로 구분합니다. 이 문서는 Windows 팀원이 따라할 수 있도록 정리한 설치·설정 매뉴얼입니다.

팀 공통 단축키
왼쪽 Shift＋Z
누르고 있는 동안 받아쓰기 → 손을 떼면 자동으로 텍스트가 입력됩니다.

1. 시스템 요구사항

항목요구사항
OSWindows 11 (Windows 10은 공식 미지원)
RAM8GB 이상 권장
네트워크최초 로그인 및 음성 처리에 인터넷 연결 필요
마이크내장 또는 USB/블루투스 마이크
Windows 10 사용자: 공식 지원 대상이 아닙니다. 회사 PC가 Windows 10이면 IT에 Windows 11 업그레이드 요청 후 진행해 주세요.

2. 어디서 다운받나

공식 사이트 외 다른 경로(소프트닉, 토렌트 등)에서 받지 마세요. 가짜 설치 파일이 돌아다닙니다.

1

구글에서 검색

구글에 typeless download 또는 typeless 다운로드 로 검색합니다.

또는 주소창에 직접 입력:

www.typeless.com/downloads

2

“Download for Windows” 버튼 클릭

페이지에 macOS / Windows / iOS 다운로드 옵션이 보입니다. Windows 쪽 버튼을 누르면 설치 파일(.exe 또는 .msi)이 다운로드 폴더로 받아집니다.

확인 포인트: URL이 정확히 typeless.com 인지 확인하세요. typeless.info, typeless.en.softonic.com 같은 비공식 사이트는 피합니다.

3. 설치하기

1

설치 파일 실행

다운로드 폴더에서 받은 파일을 더블클릭합니다.

Windows에서 "Microsoft Defender SmartScreen에서 PC를 보호했습니다" 경고가 뜨면, 게시자가 신뢰할 수 있는지 확인 후 추가 정보 → 실행 을 누릅니다.

2

설치 마법사 진행

약관에 동의하고 다음 → 설치 → 마침 을 차례로 눌러주세요. 2분 안에 끝납니다.

3

Typeless 실행

설치 후 자동 실행되거나, 시작 메뉴에서 Typeless 를 검색해 엽니다.

트레이(작업 표시줄 우측 하단)에 Typeless 아이콘이 나타나면 정상입니다.

4. 최초 실행 · 권한 설정

1

계정 만들기 / 로그인

개인 지메일 계정으로 가입합니다. 무료 플랜으로 시작 가능하며, 팀 라이선스가 필요하면 사업팀장에게 문의해 주세요.

2

마이크 권한 허용

처음 실행 시 Windows가 "Typeless가 마이크에 접근하도록 허용하시겠습니까?" 를 물어봅니다. 예 / 허용을 선택합니다.

나중에 변경하려면: 설정 → 개인 정보 및 보안 → 마이크 → Typeless 켜기

3

접근성 권한 (입력 기능)

받아쓴 텍스트를 다른 앱 입력창에 자동으로 넣기 위해 권한 허용을 요구할 수 있습니다. 모두 허용합니다.

5. 단축키를 왼쪽 Shift＋Z 로 변경

기본값은 오른쪽 Alt 인데, 팀에서는 왼쪽 Shift + Z 로 통일합니다. (왼손만으로 누를 수 있어 마우스를 놓지 않고 받아쓸 수 있습니다.)

1

설정 열기

트레이의 Typeless 아이콘을 우클릭 → Settings (설정) 선택. 또는 앱 화면에서 톱니바퀴 아이콘을 클릭합니다.

2

Shortcut / Hotkey 메뉴 진입

설정 안에서 Shortcut, Hotkey, 또는 Keybinding 항목을 찾습니다.

3

모드는 “Push-to-Talk” 로

입력 모드를 Push-to-Talk (누르고 있는 동안 녹음) 로 선택합니다. Toggle 모드는 사용하지 않습니다.

4

단축키 설정

"Set Shortcut" 또는 "Change Hotkey" 버튼을 누른 뒤, 키보드에서 왼쪽 Shift 키를 누른 채 Z 키를 함께 눌러주세요.

입력란에 Left Shift + Z 또는 LShift + Z 로 표시되면 성공입니다. Save / Apply 를 눌러 저장합니다.

충돌 주의: 일부 게임이나 한글 입력기에서 왼쪽 Shift＋Z 가 다른 기능에 잡혀있을 수 있습니다. 충돌이 의심되면 왼쪽 Shift＋왼쪽 Alt 또는 오른쪽 Alt 로 임시 변경 후 사업팀장에게 알려주세요.

6. 실제 사용법

1

입력하고 싶은 앱에 커서를 둡니다

메일, 슬랙, 노션, 카톡, 메모장, 어떤 앱이든 텍스트 입력창에 커서를 두세요.

2

왼쪽 Shift＋Z 를 누른 채로 말합니다

키를 떼지 말고 자연스럽게 말합니다. 너무 또박또박 끊어 말할 필요 없습니다.

3

키에서 손을 떼면 텍스트가 자동 입력됩니다

AI가 어, 음 같은 추임새를 제거하고 문장 부호도 자동으로 넣어 입력해 줍니다.

꿀팁: 한국어와 영어를 섞어 말해도 자동 인식됩니다. 회의 메모, 메일 초안, 슬랙 답장 모두 사용 가능.

7. 자주 묻는 질문 / 문제 해결

Q. 단축키를 눌러도 반응이 없습니다.

  • 트레이에 Typeless 아이콘이 떠 있는지 확인 (실행 중이어야 작동)
  • 설정에서 Run at startup (시작 시 자동 실행) 켜두면 편함
  • 다른 앱(게임, 한글, IME)이 같은 키를 선점하고 있는지 확인

Q. 마이크가 인식되지 않습니다.

  • Windows 설정 → 시스템 → 소리 → 입력 에서 기본 마이크 확인
  • 마이크 사용 권한이 Typeless에 켜져 있는지 확인
  • USB 마이크는 다른 포트에 꽂아 재인식

Q. 받아쓴 결과가 엉뚱한 곳에 입력됩니다.

  • 말하기 전 커서가 입력하고 싶은 자리에 정확히 놓여 있는지 확인
  • 키를 누르는 동안 다른 창이 포커스를 가져가지 않도록 주의

Q. 보안이 걱정됩니다. 음성이 저장되나요?

공식 정책상 Zero Data Retention (보관하지 않음) 입니다. 다만 민감한 고객 정보(개인정보, 계약 조건 등)는 텍스트로 직접 입력하는 것을 권장합니다.

Q. 회사 PC에 설치해도 되나요?

설치 전 정보보안팀 가이드에 따라 사용 가능 여부를 확인해 주세요. AI사업2팀은 사업팀장 승인 후 사용합니다.
