Claude 추출 · 판단

Workflow

메시지에서 캘린더까지,
다섯 단계

한 메시지가 들어오면 봇은 이 순서대로 움직입니다.

1

메시지 감지

지정한 디스코드 채널을 실시간 감시합니다. 봇이 꺼져 있던 동안 쌓인 메시지는 재시작 시 캐치업으로 한 번에 따라잡습니다.

bot.py
2

일정 추출

Claude CLI를 호출해 텍스트·이미지에서 제목·날짜·시간·장소를 구조화된 JSON으로 뽑아냅니다. 카카오톡 캡처는 비전 OCR로 읽습니다.

extractor.py
3

판단

일정과 무관한 메시지는 조용히 넘깁니다. "내일"처럼 날짜가 모호하면 사용자에게 되물어 확정합니다.

4

캘린더 등록

Claude CLI와 Google Calendar MCP를 통해 실제 캘린더 이벤트를 생성합니다.

calendar_client.py
5

회신 & 기록

등록 결과를 [수정]·[삭제] 버튼이 달린 임베드로 회신하고, SQLite에 임베드↔이벤트 매핑을 저장합니다.

state.py
Inputs

텍스트 일정 메시지

"8/16 15시 제주 렌터카 픽업" 같은 문장을 자동으로 추출·등록합니다.

→ 결과 임베드 + [수정]/[삭제]

카톡 캡처 · 안내문 이미지

비전 OCR로 이미지 속 일정을 읽습니다. 상대 날짜가 보이면 되묻고 확정합니다.

→ OCR 추출·등록

일정과 무관한 메시지

잡담·링크 등 일정이 아닌 메시지는 반응 없이 조용히 넘깁니다.

→ 무시 (FR-04)

봇 다운타임 후 재시작

꺼져 있던 동안 들어온 메시지를 마지막 처리 지점부터 캐치업해 누락 없이 처리합니다.

→ 캐치업 (FR-26)
After

등록한 뒤에도,
한마디면 됩니다

틀렸거나 바뀌었을 때, 캘린더를 직접 열 필요가 없습니다.

답장으로 수정

결과 임베드에 "수정: 내일 14시"라고 답장하면 이벤트가 갱신됩니다.

[수정] 버튼

임베드의 [수정] 버튼을 누르면 모달 입력창으로 바로 갱신합니다.

[삭제] 버튼

[삭제] 버튼 한 번으로 캘린더에서 해당 이벤트를 지웁니다.

Architecture

여섯 개의 파일로 끝

각 파일이 한 가지 역할만 맡습니다.

bot.py

discord.py 메인 — 채널 감시, 캐치업, 임베드·버튼, 답장 처리.

extractor.py

추출 ① — Claude CLI로 텍스트·이미지에서 일정 정보를 인식.

calendar_client.py

등록 ② — Claude CLI + Google Calendar MCP로 이벤트 생성.

claude_runner.py

Claude CLI subprocess 공용 호출 + JSON 응답 파서.

prompts.py

추출·등록·수정·삭제 프롬프트 모음.

state.py

SQLite — 캐치업 커서와 임베드↔이벤트 매핑 보존.
