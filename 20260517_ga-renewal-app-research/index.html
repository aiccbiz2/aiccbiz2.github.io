INSIGHT 01

진짜 페인은 감정노동 회피

표면 페인 = "수납 관리". 진짜 페인 = "세입자에게 미납 독촉하기 어색하다." → 중립적 제3자(자리톡)가 카톡 발송 → 미납 90% 감소. 우리도 "GA → 고객 갱신 안내" 자동화 가능.

INSIGHT 02

무료 워크플로우 락인 → 부가 유료

임대인은 100% 무료. 세입자 카드결제 수수료·환급 서비스로 수익화. 우리도 동일 구조 — 갱신 알림 무료, 알림톡·세무·B2B 영업소로 유료화.

INSIGHT 03

카카오톡이 핵심 인프라

한국 1인 사업자 도구는 카톡을 어떻게 쓰느냐가 승부. 자리톡의 카톡 고지서 = 우리의 카톡 알림톡. 동일한 인프라 위에서 동일한 차별화 작동.

INSIGHT 04

양면 시장은 자본 게임

자리톡 480만 트래픽 = 10년 + 수십억. 1인 SaaS가 그대로 따라하면 위험. 우리는 단면(GA)으로 시작 → 인플루언서·영업소 침투로 1만 명까지.

⑤ Build + GTM

빌드는 쉽다.
딜리버리가 진짜 게임.

BUILD — 6주, 1인 가능

5필드 CRUD + 푸시알림 = To-Do 앱 수준. Flutter+Supabase 또는 PWA+카카오톡.

  • 주 1~2: 와이어프레임 + 디자인 + DB 스키마
  • 주 3~4: 핵심 CRUD + 알림 로직
  • 주 5: 푸시/알림톡 통합 + 회원가입
  • 주 6: 베타 테스트 (인터뷰한 GA 10명)

GTM — 광고는 안 먹힌다

40~50대 GA는 SNS 광고 핏 아님. 신뢰 산업 → 광고 한 번에 자기 고객 DB 안 넣음. 작동하는 채널은 셋:

  • 동료 추천 (전환률 30~50%)
  • 네이버 카페 / 카톡 오픈챗 (전환률 5~10%)
  • 영업소 단위 시연 (1소 = 30~80명 도입)

3단계 GTM 플레이북

PHASE 1 · 0~3개월
100

Trust Building

인터뷰한 GA 10명 → 베타 전환. 동료 5명씩 소개. 네이버 카페·카톡방 침투. 광고 0원.

PHASE 2 · 3~9개월
1K

Champion-Led Growth

인플루언서 GA 1명 락인 → 영업소 30~80명 도입. 이직 모먼트 콘텐츠. "이직해도 고객 따라옵니다" 메시지.

PHASE 3 · 9~24개월
10K

Network + Paid

레퍼럴 프로그램. 카카오모먼트·유튜브 광고. 월 ARR 470만원 → 연 5.6억 매출.

Verdict

유리 5 · 위험 5.

✓ 유리

  • TAM 충분 — 30만 × 5% × 4,900원 = 연 88억
  • 2029 분급제 — 갱신 도구가 필수품으로 격상
  • 이직률 54% — 매년 시장의 절반이 winback 모먼트
  • 결제 인프라 ✓ — 모두GA 연 5.5만원 결제 시장
  • 경쟁 빈자리 — "GA 1인 사업자 자산" 카테고리 무주공산

⚠ 위험

  • 쿠콘+한자산 — 6~12개월 윈도우
  • 카톡 알림 commodity 위협 — 메시지로 풀어야 함
  • 고령화 — UX 단순함이 생존 조건
  • 무료 함정 — 헌신도 낮으면 락인 약함
  • 빅4 GA 자체 솔루션 — top-down 도입 시 위축
